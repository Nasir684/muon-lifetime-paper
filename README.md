# muon-lifetime-paper

Pre-registration protocol v1.1 and validated analysis pipeline for
"Poisson-Certified Muon Counting: A Hardware-Validated, Dead-Time-Corrected
Channel Applied to the Positive-Muon Lifetime."

- `preregistration_v1.1.pdf` — locked protocol, deposited and time-stamped before data collection (release `v1.0-prereg`)
- `muon_lifetime_mc.py` — Monte-Carlo pipeline: unbinned ML fit, profile-likelihood interval, Fano certification, parametric-bootstrap KS, unblinding-gate validation

Parent hardware verification: QCID-Sigma v5.4, Zenodo 10.5281/zenodo.23378709.
